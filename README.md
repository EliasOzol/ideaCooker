# ideaCooker

One idea a day, each with a README and a small working prototype.

Every idea lives in its own `yyyy-mm-dd-<slug>/` folder. Each README ends with a status:

- 🔴 **Idea**: nothing runs yet
- 🟡 **Prototype**: works, with clear gaps
- 🟢 **Done**

New ideas are made with [Idea Cooker](2026-11-25-idea-cooker/), which was itself one of the ideas. It also lists every idea with its status.
